## Course objectives

By the end of the course, you should be able to derive governing equations for mechanical, electrical, electromechanical, fluid, and thermal systems. You will use time responses, transfer functions, state space, and block diagrams to explain how models behave, then compare their predictions to simulations or measurements.

## Books and tools

- **Optional text:** William J. Palm III, *System Dynamics*, 4th ed., McGraw Hill.
- **Computing:** Use the MATLAB, Simulink, or Python resources linked with individual assignments and projects. Several projects include a code guide and setup check in the starter package.
- **Browser labs:** Open the interactive activities from the schedule or lecture pages. The exercises include reference values you can use without the live simulation.
