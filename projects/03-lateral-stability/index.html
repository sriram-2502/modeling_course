Project 03 · Vehicle dynamics

Keeping a Vehicle Stable

Compare linear and nonlinear tire models for straight-line recovery and cornering.

Project handout (PDF) Code guide (PDF) Starter code (ZIP)

The modeling question

Does a tire that recovers well from a small disturbance also maintain stability in a high-speed turn? The planar model uses lateral velocity and yaw rate at a fixed forward speed.

What you do

Compare the linear approximation with the full lateral tire curves. Test small and larger disturbances for straight-line recovery and steady cornering. Use simulated trajectories, phase portraits, and the project criteria to support a tire recommendation.

Review phase portraits and stability.

Vehicle recovery replay

Predict. After a lateral disturbance, can the dynamic state recover while the vehicle is still off its nominal path?

Try. Run the straight or steady-turn case. Compare the top-down path with the phase trajectory at the same instant.

Explain. At the final time, are the changes in lateral velocity and yaw rate close to zero? Has the vehicle rejoined the nominal path?

Reference case

In this linear bicycle model at 18 m/s, lateral velocity and yaw rate return toward their nominal values. The X–Y path can retain an offset because position accumulates motion. The project explores how nonlinear tires can change the recovery.
